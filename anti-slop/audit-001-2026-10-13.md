## Executive Summary

The *Four Seas* codebase exhibits exceptional thematic craftsmanship, authentic historical terminology, responsive layout design, and zero generic AI buzzwords or fake testimonials. However, this audit identified 9 actionable violations across the three antislop tiers: 5 **HIGH** priority Hard Gate issues (em dash typography, low-contrast gold text, touch tap targets, unhandled dynamic import error states, missing DESIGN.md), 2 **MEDIUM** priority Purpose-Gate issues (backdrop blur saturation, decorative button arrows), and 2 **LOW** priority Quality Lock issues (uniform 999px pill border-radius overuse, missing theme switch in Settings).

---

## Numbered Findings List

### [01] HIGH Priority (Hard Gate) — Rule R-02 (Copywriting)
- **Location**: `src/routes/+page.svelte`, `src/lib/components/VenueBar.svelte`, `src/lib/components/Market.svelte`, `src/lib/components/Creator.svelte`, `src/lib/components/Drawer.svelte`, `src/lib/components/RiddleDialog.svelte`, `src/lib/components/SwipeCard.svelte`
- **Violation**: Em dash character (`—`) appears in user-facing UI text, labels, and dialog prompts (e.g., `place(selected)} — {CITY[selected].blurb}`, `Where does it lead? Choose carefully — a wrong guess...`, `Codex — how everything works`).
- **Remediation**: Replace all em dashes with commas, colons, parentheses, or periods to maintain natural human prose.

### [02] HIGH Priority (Hard Gate) — Rule R-25 (Color Contrast)
- **Location**: `src/app.css` (line 13) and usages in `VenueBar.svelte`, `PeopleStack.svelte`, `Drawer.svelte`, `Creator.svelte`, `Codex.svelte`, `+page.svelte`
- **Violation**: Text colored with `--gold: #b8902e` against light parchment background `--paper: #f2e8d2` yields a contrast ratio of only **2.44:1**, failing the WCAG AA minimum of 4.5:1.
- **Remediation**: Introduce a dedicated `--gold-text: #7c5900` for light theme typography (ratio **5.25:1**, WCAG AA PASS) while keeping `#b8902e` for borders and non-text accents.

### [03] HIGH Priority (Hard Gate) — Rule R-03 (Mobile Responsiveness & Tap Targets)
- **Location**: `src/lib/components/VenueBar.svelte` (`.action-pill`, `.rest`, `.bld-item`)
- **Violation**: Interactive sub-action buttons and building items have rendered heights between 22px and 26px with minimal vertical padding (`2px 8px`, `3px 6px`), violating the mobile 44px tap target guideline.
- **Remediation**: Increase touch padding and set `min-height: 44px` (or `min-height: 38px` with safe touch expansion) for touch devices.

### [04] HIGH Priority (Hard Gate) — Rule R-27 (UI States)
- **Location**: `src/routes/+page.svelte` (`{#await loadMarket()}`, `{#await loadDrawer()}`, `{#await loadCreator()}`, `{#await loadCityFresco()}`)
- **Violation**: Dynamic component imports use `then` without `{:catch error}` blocks, risking silent unresponsiveness if an offline chunk or network hiccup occurs.
- **Remediation**: Add explicit `{:catch err}` fallback blocks providing visual feedback and a retry action.

### [05] HIGH Priority (Hard Gate) — Rule R-37 (Design Direction Required)
- **Location**: Project root (`DESIGN.md` missing)
- **Violation**: The project does not have a formal `DESIGN.md` defining its historical visual identity, typography rationale, and explicit liveliness dials.
- **Remediation**: Create `DESIGN.md` articulating the woodblock ink-wash identity, palette harmony, and explicit dials (`ENERGY 2 / RHYTHM 3 / MOTION 2`).

### [06] MEDIUM Priority (Purpose-Gate) — Rule R-10 (Glassmorphism)
- **Location**: `src/lib/components/WorldMap.svelte`, `src/lib/components/CityFresco.svelte`, `src/routes/+page.svelte`
- **Violation**: `backdrop-filter: blur(...)` is applied across 7 separate elements simultaneously (HUD pill, zoom controls, map legend, photo toast, photo caption, fresco panels), exceeding the dose cap (max 1–2 elements).
- **Remediation**: Remove `backdrop-filter` from secondary controls (zoom, legend, toasts) using solid opaque dark backgrounds (`rgba(8, 12, 19, 0.95)`), reserving blur strictly for the central HUD pill.

### [07] MEDIUM Priority (Purpose-Gate) — Rule R-08 (Button Arrows)
- **Location**: `src/lib/components/Creator.svelte` (`Choose traits →`, `Done with N →`) and `src/routes/+page.svelte` (`Leave {city} now →`)
- **Violation**: Trailing arrows (`→`) are placed on standard buttons as pure decoration with no written visual distinction between routing and form state submission.
- **Remediation**: Remove decorative arrows from standard buttons; retain arrows only where depicting an actual physical travel leg (e.g. departure destination).

### [08] LOW Priority (Quality Lock) — Rule R-11 (Border Radius)
- **Location**: `src/app.css`, `VenueBar.svelte`, `Market.svelte`, `WorldMap.svelte`, `Creator.svelte`, `Drawer.svelte`, `+page.svelte`
- **Violation**: `border-radius: 999px` is applied to over 30 elements, flattening the UI into repetitive pill shapes.
- **Remediation**: Establish a structured radius scale in `app.css` (`--radius-sm: 4px`, `--radius-md: 6px`, `--radius-lg: 10px`), reserving pill shape only for status chips and roundels.

### [09] LOW Priority (Quality Lock) — Rule R-21 (Dark Mode)
- **Location**: `src/routes/+page.svelte` (Settings modal)
- **Violation**: While dark mode CSS variables exist in `app.css`, the Settings dialog lacks an explicit Theme selector, leaving dark mode forced or bound solely to OS preference.
- **Remediation**: Add a 3-way theme selector (`Auto / System`, `Light (Parchment)`, `Dark (Lacquer)`) to the Settings modal.
